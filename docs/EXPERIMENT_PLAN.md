# Proposed lifecycle experiments

| Hypothesis | Audience | Intervention | Primary metric | Guardrail |
| --- | --- | --- | --- | --- |
| Earlier activation guidance improves engagement | New accounts before first value event | Contextual onboarding checklist | Activation within 7 days | Support contacts |
| Timely outreach improves return usage | Consenting low-usage active accounts | Targeted re-engagement message | 14-day return rate | Unsubscribe rate |
| Product education improves sustained use | Infrequent active users | Use-case tutorial | 30-day active retention | Notification opt-outs |

Randomise eligible accounts between intervention and existing experience. Define activation and retention events before launch. Set sample size from measured baseline and minimum detectable effect; analyse by assigned group. Avoid overlapping campaigns where possible.

These experiments are proposals, not completed tests. The synthetic dataset cannot establish intervention lift, longitudinal retention or causal effects.
